# projeto-media-alunos

📊 Calculadora de Médias de Alunos

Este programa em C# permite que você registre notas de múltiplos alunos e calcule suas médias automaticamente.

🔹 Funcionalidades

- Solicita ao usuário a quantidade de alunos.

- Permite digitar o nome de cada aluno.

- Recebe duas notas para cada aluno, garantindo que sejam válidas (entre 0 e 10).

- Calcula a média de cada aluno.

- Mostra todas as médias.

- Identifica e exibe o aluno com a maior média.

🔹 Objetivo

- O programa foi desenvolvido para fins educacionais, ajudando a praticar:

- Entrada e saída de dados no console

- Uso de arrays e loops

- Validação de dados

- Operações matemáticas simples
